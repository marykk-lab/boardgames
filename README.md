# 🎲 Boardgames Shop

An e-commerce web application for buying and managing board games.  
Built with **Django**, **Tailwind CSS**, and **Stripe**, it offers both a smooth shopping experience for users and a powerful admin panel for store management.

## ✨ Features

### 🛍️ User Side
- Browse and search board games with images, descriptions, and prices  
- Add games to **cart** and **favorites**  
- Checkout with **Stripe payment integration**  
- Manage personal orders and purchase history  

### ⚙️ Admin Panel
- Manage board games (add, edit, delete)  
- Oversee customer orders and payments  
- Track inventory and sales  
- Manage users and store data  

---

## 🛠 Tech Stack

- **Backend:** Django (Python)  
- **Frontend:** HTML, Tailwind CSS, AJAX (JavaScript)  
- **Database:** SQLite (default)  
- **Payments:** Stripe API
